# Prompt-first 구현 안내

RED와 BLUE는 독립적으로 파일과 자유 지시문을 받는다. 프롬프트 버전은 이름과 함께 저장·불러올 수 있다. 기본 복사 문구는 원본 PDF 첨부를 요청하며 추출문은 포함하지 않는다. 추출문과 선택한 Harness 지침 포함은 고급 옵션이다. 요청 지시문 기록은 실제 실행의 증명이 아니다.

외부 답변은 붙여넣거나 JSON·TXT·Markdown으로 가져온다. BLUE Markdown 결함 표는 행별 지적으로 읽고 뒤따르는 보고서를 별도로 보존한다. 원응답도 보존한다. RED의 불확실한 원문 위치는 후보를 미리보고 확인해 선택하며, 직접 연결도 가능하다. 직접 PDF 편집과 접힌 자동 실행·CLI·코드 harness 경로도 유지한다.

그림·표의 구조화된 외부 응답 내보내기는 후속 범위다. 검증 결과는 해당 변경의 실행 기록을 참조한다.
