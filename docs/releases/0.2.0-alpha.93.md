# Falsify Workbench 0.2.0-alpha.93

행사 페이지(event.html)의 결과 화면과 논문 출처 표기를 보강했습니다.

- AI 검증 결과(찾아냈어요, 근처를 짚었어요, 못 찾았어요)에 「내가 고친 곳」을 함께 보여줍니다.
  - 쪽 번호와 바꾸기 전후 글자가 나와서, AI가 짚은 곳과 비교할 수 있습니다.
  - 제출한 기기에 접수번호와 함께 저장해 둔 내용이라, 「내 기록」에서 다시 열어도 보입니다.
  - 부스 태블릿(키오스크)에서는 다음 분께 넘기면 지워집니다.
- 논문 출처를 표시합니다.
  - 논문 고르는 화면에 "미션 논문은 모두 arXiv에 CC BY 4.0으로 공개된 논문이에요. 부스에서 보는 결함은 방문자가 게임을 위해 심은 거예요."를 넣었습니다.
  - 편집 화면에는 「원문 arXiv ID · CC BY 4.0 · 게임용으로 고친 사본」을 원문과 라이선스 링크와 함께 보여줍니다.
  - 검색 결과에도 라이선스와 원문 링크가 나옵니다.
- 「못 찾았어요」의 기본 안내 문구를 "AI는 다른 곳을 짚었어요. 심어 둔 결함은 AI 눈을 피했어요."로 바꿨습니다.
- 서버(Worker)는 바뀌지 않았습니다. 작업대 본 화면(index.html)은 버전 번호만 바뀌었습니다.
