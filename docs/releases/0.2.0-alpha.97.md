# Falsify Workbench 0.2.0-alpha.97

행사 전날 점검에서 나온 불편을 고쳤습니다.

**제출과 기회**
- 「왜 결함인가요」에 줄을 바꿔 써도 제출됩니다. 줄바꿈은 띄어쓰기로 바꿔 접수하고, 너무 긴 이유는 잘라서 받습니다.
- 고친 곳을 지우고 다른 곳을 고치면, 지운 곳의 유형과 이유가 새 곳에 붙지 않습니다. 같은 자리를 다시 고치면 그대로 남습니다.
- 기회 3번을 다 쓰면 결과 화면의 버튼이 「내 기록 보기」로 바뀝니다. 철회한 제출은 기회로 세지 않습니다.
- 제출 화면에서 한도에 걸리면 「내 기록 보기」 버튼이 함께 나옵니다.

**결과 화면**
- 다시 불러올 때 이 탭에 이어서 할 고친 곳이 있으면, 끝난 결과보다 「이어서 할까요?」를 먼저 묻습니다. 기다리는 중인 결과는 전처럼 바로 엽니다.
- AI 검증을 기다리는 동안 앞에 몇 건이 남았는지 보여 줍니다.
- 15분이 지나 자동 확인을 멈추면 시계도 멈추고, 「결과 다시 보기」를 눌러 달라고 안내합니다.
- 쪽 정보가 없는 AI 설명은 「AI 메모」라는 제목으로 보여 줍니다.

**부스 태블릿**
- 결과를 기다리는 동안에는 3분이 지나도 화면을 지우지 않습니다. 16분 동안 손대지 않았을 때만 「계속하시겠어요?」를 묻습니다. 결과가 나오면 그때부터 3분을 셉니다.
- 티켓을 휴대폰으로 찍어 두라고 안내하고, 복사 버튼은 뺐습니다.
- 바깥으로 나가는 링크는 눌리지 않습니다. 소스 코드 링크는 예외입니다.

**내 AI에게**
- 논문을 바꾸거나 다시 도전하면 이전 답과 결과를 지웁니다.
- 오류 줄에 영어 코드 대신 문장을 보여 줍니다.
- 둥근 따옴표가 섞인 답도 고친 곳을 빠뜨리지 않고 적용합니다.
- 직접 고친 곳은 「AI와 숨긴 결함」이 아니라 「내가 숨긴 결함」으로 표시합니다.

**논문 검색**
- 이미 연 논문을 검색 결과에서 다시 눌러도 고친 곳이 지워지지 않습니다.
- 논문을 여는 중에 다른 논문을 누르면 무시합니다.
- 한글로 검색해 결과가 없으면 영어로 찾아보라고 안내합니다.
- 검색으로 연 논문에도 CC 라이선스를 표시합니다. 이 항목은 서버(Worker)도 함께 바뀝니다.

**화면**
- 데스크톱 편집 화면에서 쪽 넘김 막대 뒤로 본문 글자가 비치지 않습니다.
- 휴대폰이 다크 모드여도 행사 페이지는 밝은 화면을 유지합니다.
- 휴대폰에서 「원래대로」 버튼을 「바꾸기」 아래에 맞췄습니다.
