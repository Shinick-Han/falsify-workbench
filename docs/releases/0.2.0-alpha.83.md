# Falsify Workbench 0.2.0-alpha.83

BLUE 양면 PDF 대조 뷰어 및 인용 하이라이트 점프, RED 본문·표/그래프 연속 편집 브리지, 검수(H1) 실시간 솔라리 스코어보드 및 미판정 필터를 추가했습니다(Phase 2).

- **BLUE 양면 논문 원문 대조 뷰어 & 인용 하이라이트 점프**: BLUE에서 PDF를 열면 브라우저 로컬 PDF.js 렌더러로 원문 대조 뷰어(`#blue-paper-viewer`)를 함께 띄우며, 데스크톱 `원문과 나란히 보기` / `1단 위아래 보기` 전환과 확대·축소를 지원합니다. 웹 BLUE·로컬 BLUE·외부 응답·Layer 0 센서 카드의 `원문에서 보기`를 누르면 해당 쪽으로 자동 이동해 인용 문장을 하이라이트합니다.
- **RED 본문 → 표·그래프 원클릭 연속 편집**: 본문 직접 편집 직후 `#red-visual-section`이 숨겨지던 대신 `본문 수정 반영하고 표·그래프 열기` 안내 배너를 표시해, 클릭 한 번으로 본문 수정 PDF 생성과 표·그래프 편집기 진입을 이어 줍니다.
- **검수(H1) 실시간 솔라리 스코어보드 및 미판정 필터**: 검수 상단에 4분할 실시간 집계 타일(주입 결함 탐지 · 타당 지적 · 순수 오탐 · 기존·경계·오류)을 표시하고, `미판정만 보기` 토글과 `다음 미판정으로` 점프 버튼을 제공합니다.
