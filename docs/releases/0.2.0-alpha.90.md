# Falsify Workbench 0.2.0-alpha.90

행사 페이지(event.html)의 고치기와 수정본 만들기를 새로 짰습니다. 이제 고친 곳은 항상 그 자리에 들어갑니다. 1인 5회 제한, 경품 규칙, 동의 문구 v3, 표식 검사는 그대로입니다.

- **수정본 만들기**:
  - 고친 곳마다 원래 글자를 지우고 그 자리에 새 글자를 씁니다(MuPDF). 문단 재배치, 글꼴과 그림 글자 검사, 거절 단계를 모두 뺐습니다.
  - 실패는 수정본 도구를 불러오지 못했을 때 하나뿐이고, 「다시 시도」로 이어집니다.
  - 새 글자가 길면 글자 폭과 크기를 줄입니다. 그래도 넘치면 아래 줄로 이어 쓰고, 새 글자는 하나도 빠지지 않습니다.
  - 원래 글자는 PDF 안에서도 지워집니다. 새 글자는 원래 문장 순서대로 읽히고, 복사와 검색이 됩니다.
  - 쪽 화면의 글자 위치가 실제 PDF와 조금 어긋나도 그 줄에서 원래 글자를 찾아 정확히 그 글자만 바꿉니다. 위첨자 옆 쉼표를 지키고, 돌아간 쪽도 맞게 고칩니다.
- **고치기**:
  - 단어 누르기, 문단 전체 고치기, 찾아 바꾸기, 레시피, 내 AI에게가 같은 고친 곳 목록을 씁니다.
  - 문단 전체 고치기는 누른 단의 그 문단만 열고, 바뀐 낱말만 고친 곳으로 남깁니다.
  - 찾아 바꾸기는 한 곳이면 바로 고치고, 여러 곳이면 고를 목록을 보여 줍니다.
  - 고친 단어를 다시 누르면 「원래대로」로 되돌립니다. 폰에서도 고친 곳 개수를 누르면 목록이 열리고, ×로 지웁니다.
- **키오스크**: 「다음 분께 넘기기」 뒤에 앞사람의 논문을 이어서 볼지 묻지 않습니다.
- **속도**: 행사 페이지는 작업대 전용 문단·표 편집 엔진(약 7MB)을 받지 않습니다.
- 작업대 본 화면(index.html)의 동작은 바뀌지 않았습니다.
