# Falsify Workbench 0.2.0-alpha.85

AWS Community Day(2026-11-22) 부스에 라이브 AI 판정을 더했습니다. 방문자가 수정본을 제출하면 운영자의 `watch`가 곧바로 BLUE를 돌려 보통 몇 분 안에 접수번호로 결과를 게시하고, 행사 페이지는 그 결과를 스스로 확인해 보여 줍니다. 마감 뒤에는 `final`이 놓친 접수를 더 센 모델로 다시 봅니다.

- **라이브 판정** (`tools/booth` `watch`): `received` → `reviewing` → `judged` + 게시. Claude Sonnet 5.5 `live` 프로파일, 동시 작업 기본 12개, 재시작하면 같은 작업으로 이어 갑니다.
- **마감 후 재검증** (`final`): 라이브에서 놓친 접수를 Claude Opus 5.5로 다시 보고, 사람이 확인한 뒤 `--apply`로만 게시합니다. 이미 받은 즉석 선물은 유효합니다.
- **채점 수정**: 호스팅 BLUE finding의 쪽을 `segmentId`에서 읽어, 모든 접수가 `missed`로 채점되던 문제를 고쳤습니다.
- **행사 페이지 결과 카드**: 게시 전에는 15초(3분까지), 이후 30초(15분까지) 간격으로 확인하고 `Retry-After`를 따릅니다. 결과별 문구, 「다시 도전하기」, 최근 접수 5건.
- **동의문 v2**: 제출 직후 수정본 PDF만 Anthropic에 보내고 마감 후 한 번 더 보낼 수 있다고 알립니다. 동의문은 버전별로 저장해 서버가 알려 준 버전의 문구만 보여 줍니다.
- **행사 Worker**: `BOOTH_CONSENT_VERSION` `2026-11-22.v2`, 확인 경로 한도 `BOOTH_CLAIMS_PER_IP_HOUR` 8000·`BOOTH_CLAIMS_PER_HOUR` 15000, 모든 응답에서 `Retry-After` 공개.
