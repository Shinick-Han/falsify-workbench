# Falsify Workbench 0.2.0-alpha.91

행사 페이지(event.html)의 제출 화면을 줄였습니다.

- 동의 요약, 「동의 내용 전체 보기」, 「동의 내용을 읽었고 동의해요」 확인란을 뺐습니다. 「AI에게 제출하기」를 누르면 바로 제출됩니다. 서버에는 지금 부스 설정의 동의 버전을 그대로 보내고, 버전이 바뀌었으면 새 버전으로 한 번 더 보냅니다.
- 「어떤 결함인가요」와 「왜 결함인가요」는 선택 사항입니다. 비워 두면 유형은 「기타」, 이유는 「설명 없음」으로 접수합니다. 고른 유형을 한 번 더 누르면 선택이 풀립니다.
- 「이 설명은 AI에게 보내지 않고 운영진만 봐요」 문구와 제출 화면 안내 문장을 뺐습니다.
- 「별명 남기기」를 뺐습니다. 결과와 경품은 접수번호와 확인키로 확인합니다.
- agent 안내(agent.html)에서 동의 단계를 뺐습니다.
- 서버(Worker)와 작업대 본 화면(index.html)은 바뀌지 않았습니다.
