# Falsify Workbench 0.2.0-alpha.88

행사 페이지(event.html)에서 논문 쪽 위의 글자를 바로 눌러 고칠 수 있게 바꿨습니다. UX 조사에서 나온 P0 항목과 방문객 문구 정리를 함께 넣었습니다. 1인 5회 제한과 경품 규칙은 그대로입니다. 동의 문구 v3는 v2와 내용이 같고 말투만 다릅니다.

- **쪽 위에서 바로 고치기**:
  - 쪽의 단어나 숫자를 누르면 그 낱말이 선택됩니다. 마우스에서는 단어 옆에 작은 창이 뜨고(Enter 바꾸기, Esc 취소), 터치 기기에서는 키보드 위에 편집 막대가 뜹니다(‹ ›로 단어 이동). 화면 폭이 아니라 입력 방식으로 정합니다.
  - 바꾼 글자는 원래 글꼴, 굵기, 기준선에 맞춰 그 자리에 그립니다(booth-patch).
  - 「문단 전체 고치기」는 종이 모양 문단 편집기를 엽니다.
  - 폰은 미션의 힌트 위치를 확대한 채로 열고, −, +, 전체 쪽 버튼이 있습니다. 쪽 캔버스는 한 변 4096px, 전체 약 16.7M 픽셀을 넘지 않습니다.
  - 문단 목록은 화면에서 숨기고 스크린 리더와 키보드용으로 남깁니다. 폰에서는 찾아 바꾸기가 쪽 아래 「찾아 바꾸기」로 접힙니다.
- **폰 규칙과 추첨**: 폰에서도 「1인 5번까지」, 진행 순서, 최종 추첨 카드가 보입니다.
- **대기와 복귀**:
  - 탭으로 돌아오면 결과를 바로 확인하고, 멈춘 확인을 다시 시작합니다. 결과를 기다리는 동안 화면을 켜 둡니다.
  - 오프라인이면 「인터넷 연결이 끊겼어요」와 「다시 시도」를 보여 주고, 연결되면 다시 시도합니다.
  - 새로고침하거나 다른 앱에 다녀와도 「고친 곳 N개를 이어서 할까요?」로 이어서 할 수 있습니다.
- **키오스크 모드** (`event.html?kiosk=1`):
  - 기록은 그 탭에만 둡니다.
  - 「다음 분께 넘기기」를 누르거나, 3분 동안 조작이 없어 20초 안내가 지나면 처음 화면으로 돌아갑니다.
  - 다음 방문자는 새 게스트 세션과 기회 5번을 받습니다.
- **AI 출처 표시**:
  - AI 레시피로 고친 곳에 `AI` 표시가 붙습니다.
  - 보내기 카드 제목은 「AI와 숨긴 결함」이고 「AI 제안 · R-코드」가 붙습니다.
  - 이유 칸에는 「AI가 채운 초안 · 내 말로 고쳐도 돼요」가 뜹니다.
  - 레시피가 유효한 시각을 보여 줍니다.
- **내 AI에게**: 「복사됨 ✓」 뒤에 「다시 복사」, 붙여 넣기 안내, 중복 경고 정리, 폰의 「AI 앱으로 보내기」.
- **문구**:
  - 방문객 문구 52곳을 해요체로 맞추고, 탓하거나 의심하는 말과 내부 용어를 뺐습니다.
  - 동의 문구 v3(`2026-11-22.v3`)를 더하고 서버 설정 `BOOTH_CONSENT_VERSION`을 v3로 바꿉니다.
  - 부스 설정을 받기 전에는 동의 문구를 비워 둡니다. 예전 v1 문구가 잠깐 보이던 문제를 고쳤습니다.
- **보기**: 강제 다크 모드 끄기(`color-scheme: only light`), 회색 글씨와 입력칸 테두리의 대비 상향, 하단 링크 구분점.
- 작업대 본 화면(index.html)은 바뀌지 않았습니다. paper-workspace.js에는 쪽 문단 조회, 확대, 캔버스 상한 훅이 더해졌습니다.
