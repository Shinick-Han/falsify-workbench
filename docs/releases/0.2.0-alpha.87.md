# Falsify Workbench 0.2.0-alpha.87

행사 페이지(event.html)에 데스크탑 화면을 더하고, 폰 편집을 쉽게 바꿨습니다. 방문자 대신 AI가 결함을 심을 수 있게 결함 레시피와 agent API를 붙였습니다. 동의문, 1인 5회 제한, 경품 규칙은 그대로입니다.

- **데스크탑 (1024px 이상)**:
  - 1120px 단 위쪽에 1–2–3 단계 막대와 「내 기록」이 있습니다.
  - pick: 왼쪽에 소개와 진행 방법, 오른쪽에 미션 티켓과 늘 열린 검색창을 둡니다.
  - edit: 왼쪽에 논문 쪽을 고정하고, 오른쪽에 힌트, 고치기 패널, 문단 목록을 둡니다. 아래 막대의 고친 곳 칩에서 지우거나 다시 열 수 있습니다.
  - send: 오른쪽에 SUBMISSION 티켓을 고정합니다.
  - ticket: 탑승권 모양 티켓에 도장과 결과를 두 칸으로 보여 줍니다.
  - 1023px 이하는 alpha.86과 같은 폰 화면입니다.
- **선명한 논문 쪽**: 쪽 그림을 화면 픽셀 밀도(최대 3배)로 그립니다. 폰에서 글자가 더는 뭉개지지 않습니다. CSS 크기와 클릭 위치는 그대로입니다.
- **직접 고치기 = 찾아 바꾸기**: 「바꿀 글자」를 치면 일치하는 곳을 문맥과 함께 보여 줍니다. 하나를 고르고 「새 글자」를 넣어 「바꾸기」를 누르면 됩니다. 문단 목록은 「문단 목록에서 고르기」로 펼칩니다. send 단계에서는 「수정본 쪽 보기」로 원본 쪽과 수정본 쪽을 나란히 봅니다.
- **내 AI에게**: 미션 힌트와 해당 쪽 원문이 든 부탁 글을 복사해 ChatGPT, Claude, Gemini 같은 AI에게 붙여 넣습니다. AI가 준 답을 붙여 넣으면 바뀐 곳이 적용됩니다. 코드 블록이나 앞뒤 설명이 섞인 답, before/after 형식도 받습니다.
- **Agent 코드 / agent API**:
  - agent가 `POST /v1/booth/recipes`로 레시피를 올리면 `R-XXXXXX` 코드와 링크를 받습니다.
  - 방문자는 그 링크(`#recipe=`)를 열거나 코드를 넣어 불러온 뒤, 직접 확인하고 동의하고 제출합니다.
  - 레시피는 6시간 뒤 지워지며 개인정보를 담지 않습니다.
  - MCP 엔드포인트(`/mcp`, 도구 `list_missions`, `get_mission_text`, `create_recipe`)가 있습니다.
  - 미션 논문 본문은 `GET /v1/booth/missions/:paperId/text`로 제공합니다.
  - 안내는 `agent.html`, `agent.md`, `llms.txt`에 있고, 행사 페이지 아래에 「AI agent로 참여하기」 링크가 있습니다.
- **출처 기록**: 제출에 `assist`(manual, my-ai, agent)와 `recipeCode`를 남깁니다(D1 마이그레이션 0007). 운영 CLI의 `list`, `export`, `final`에 출처가 보입니다. AI가 심은 결함도 직접 심은 결함과 똑같이 경품 대상입니다.
- 작업대 본 화면(index.html)은 쪽 그림이 선명해진 것 말고는 바뀌지 않았습니다.
