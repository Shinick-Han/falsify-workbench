# Falsify Workbench 0.2.0-alpha.79

호스팅 AI에 게스트 세션을 더했습니다. `POST /v1/ai/guest`는 호스팅이 켜져 있고 `AI_OPEN_ACCESS`가 `true`일 때만 열립니다. 토큰은 `fsg_`와 base64url 43자이고, 소유자는 세션마다 `gst:<uuid v4>`입니다. 이 베어러는 `/v1/ai/*`에서만 받습니다. 기록, Confluence, 비밀번호, 로그아웃은 알 수 없는 토큰과 같이 거절합니다. 오픈 액세스가 꺼져 있으면 발급과 이후 `fsg_` 사용은 `403 open_access_disabled`이고, 호스팅이 꺼져 있으면 그 경로는 `404`입니다.

기본 상한은 IP당 시간당 발급 10회, 전체 발급 600회, 게스트당 업로드 10회, 작업 6회, 동시 작업 1개, 작업당 호출 8회, 업로드 본문 20971520바이트입니다. 전체 작업 150회와 전체 런타임 업로드 300회가 더 셉니다. 기본값에서 유료 호출은 시간당 1200회, 새 런타임 업로드는 300회(6291456000바이트)를 넘지 않습니다. 비밀번호 세션과 Confluence 소유자의 기존 상한은 그대로입니다.

행사 링크는 `#k=`로 접속 키를 실을 수 있습니다. 페이지는 그 값을 `sessionStorage`에만 두고 프래그먼트를 지운 뒤, 게스트 요청 본문에만 넣습니다. `event.html`과 `cloud-config.event.js`는 기본 `index.html`과 `cloud-config.js`를 바꾸지 않고 옆에 둡니다. 릴리스 ZIP에는 이 두 파일을 넣지 않습니다. 열린 모드에서는 로그인 폼과 PC 연결 UI를 숨기고, 실행이나 적용이 API를 필요로 할 때만 게스트를 발급합니다.

이벤트 API Worker는 배포하지 않았고, 운영 Worker는 오픈 액세스를 꺼 둔 상태입니다. 공개된 `event.html`은 아직 아무것도 실행하지 못합니다. 기본 페이지는 로그인이 필요합니다. 그래프 점 PDF 내보내기는 로컬 companion이 있어야 하며, 행사 페이지에서는 동작하지 않습니다. 모델을 호출하지 않았고, 익명 부하 측정은 하지 않았습니다.
