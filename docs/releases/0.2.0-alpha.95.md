# Falsify Workbench 0.2.0-alpha.95

행사 페이지(event.html)의 「내 AI에게」가 논문 전체를 보고 결함을 고르도록 바꿨습니다.

- 부탁 글(프롬프트)에 논문 한 쪽 원문을 넣지 않습니다. 대신 arXiv 공식 PDF 주소를 넣고, 방문자 AI가 논문 전체를 읽고 결함을 심을 곳을 고릅니다.
- 1단계에 「원문 PDF 받기」 버튼을 넣었습니다. PDF를 AI에 첨부하거나, 링크를 읽을 수 있는 AI라면 부탁 글만 붙여 넣으면 됩니다.
- 부탁 글에는 답 형식과 적용에 필요한 규칙만 남겼습니다. 결함 예시, 「티 나지 않게」 같은 요령, 미션 힌트, 실제 값이 든 예시는 뺐습니다. 결함은 1~5개까지 받습니다.
- AI가 논문을 열지 못하면 추측하지 말고 정해진 답을 하도록 했고, 그 답을 받으면 「AI가 논문을 열지 못했어요. 원문 PDF를 받아 AI에 첨부한 뒤 다시 물어봐 주세요.」를 보여줍니다.
- AI가 쪽 번호를 틀려도 논문 전체에서 찾아 맞는 쪽에 적용합니다.
- 「직접 고치기」의 미션 힌트와 결과 화면은 그대로입니다. 서버(Worker)는 바뀌지 않았습니다.
