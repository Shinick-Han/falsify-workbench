# Falsify Workbench 0.2.0-alpha.94

행사 페이지(event.html)에 영어 모드를 넣고, 가짜연구소 Falsify 프로젝트 링크와 기회 3번 제한을 반영했습니다.

- 영어 모드
  - 화면 위쪽 「EN」 버튼으로 바꾸고, 「한국어」 버튼으로 돌아옵니다. 기본은 한국어입니다.
  - 논문 고르기, 고치기(직접 고치기·내 AI에게), 보내기, 결과, 내 기록, 철회, 부스 태블릿 안내까지 모두 영어로 나옵니다.
  - 고치던 내용과 단계는 언어를 바꿔도 그대로 남습니다.
  - 논문 본문, 방문자가 입력한 글자, AI가 인용한 문장, 접수번호와 확인키는 번역하지 않습니다. 브라우저 자동 번역도 이 부분은 건드리지 않습니다.
  - 부스 태블릿에서는 다음 분께 넘기면 한국어로 돌아갑니다.
- AI 설명 두 언어
  - AI 검증 처리기가 설명을 한국어와 영어로 함께 받아, 화면 언어에 맞는 쪽만 보여줍니다.
- 가짜연구소 Falsify 프로젝트 링크
  - 페이지 아래 대표 링크가 https://github.com/Pseudo-Lab/Falsify 로 바뀌었습니다.
  - 이 페이지 소스(AGPL-3.0) 링크는 작게 남겼습니다.
  - AI 검증을 기다리는 동안 프로젝트를 둘러보고 GitHub에서 ★를 눌러 달라는 한 줄을 보여줍니다. 결과가 나오면 사라지고, 선물이나 기회와는 관계없습니다.
  - 부스 태블릿에서는 링크 대신 QR 코드를 보여줍니다.
- 기회 3번
  - 행사 서버의 1인 제출 한도를 3번으로 바꿉니다. 화면 문구는 서버 값을 따라갑니다.
- 작업대 본 화면(index.html)은 버전 번호만 바뀌었습니다.
