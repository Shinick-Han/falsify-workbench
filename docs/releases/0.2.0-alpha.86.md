# Falsify Workbench 0.2.0-alpha.86

AWS Community Day(2026-11-22) 행사 페이지를 방문자 폰에 맞춰 다시 짰습니다. 작업대 화면을 숨기고, 한 화면에 한 단계만 보여 주는 「도전 티켓」 흐름으로 바꿨습니다. 서버 API, 동의문, 접수 규칙은 그대로입니다.

- **행사 셸** (`event-theme.css`, event.html 전용): RED·검수·Harness 메뉴, 파일 놓기, AI 웹 실행, 외부 AI 복붙, 도구 설정을 CSS로만 숨깁니다. DOM은 그대로 두고, 가운데 480px 단으로 보여 줍니다. 기기 기본 글꼴만 쓰고 웹 글꼴은 받지 않습니다. 「소스 코드 · AGPL-3.0-only」 링크는 남깁니다.
- **네 단계** (`html[data-booth-step]`):
  - pick: 미션 티켓을 누르면 논문을 불러와 힌트 쪽을 엽니다.
  - edit: 문단을 눌러 고칩니다. 아래 고정 막대에 「고친 곳 N개 · 다음」이 있고, 「다음」을 누르면 제출할 수정본 PDF를 자동으로 만듭니다.
  - send: 바뀐 곳 diff, 결함 유형, 이유, 동의문 3줄 요약(전문은 펼쳐서)을 보여 줍니다. 코스는 항상 quick으로 보냅니다.
  - ticket: 접수번호·확인키·경과 시간·바코드가 든 검증 티켓을 보여 주고, 결과가 나오면 통과·적발·무효 도장을 찍습니다.
- **결과 표시**: `prizeMessage`가 있으면 교환권 티켓을 붙입니다. `publicNote`의 「AI가 짚은 곳」「AI가 짚은 문장」「AI 설명」 줄은 쪽·인용·AI 의견으로 나눠 보여 줍니다. 「다시 도전하기 · 기회 N번 남음」과 이 브라우저의 기록도 있고, 제출 철회는 접어 둡니다.
- 작업대 본 화면(index.html)은 바뀌지 않았습니다.
