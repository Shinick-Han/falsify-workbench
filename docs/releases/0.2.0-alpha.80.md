# Falsify Workbench 0.2.0-alpha.80

호스팅 런타임과 운영 Worker, 행사 Worker는 이 릴리스보다 먼저 운영자가 배포했습니다. 합성 PDF에서 실제 작업이 끝났습니다. `gpt-5.4-mini`는 RED와 BLUE이고, `claude-haiku-5-5`는 RED입니다.

기본 페이지는 로그인 없이 열립니다. 게스트 세션은 접속 키 없이 발급됩니다. 운영 Worker 상한은 세션 21600초, IP당 시간당 발급 20회, 전체 발급 300회, 게스트당 업로드 10회, 전체 업로드 120회, 업로드 본문 20971520바이트, 게스트당 작업 6회, 동시 작업 1개, 작업당 호출 8회, 전체 작업 40회입니다. 게스트 토큰 예산은 86400초 창에서 3000000입니다.

행사 Worker의 게스트 작업 상한은 같고, IP당 시간당 발급은 60회, 게스트 토큰 예산은 4000000입니다.

그래프 점 PDF 내보내기는 로컬 companion이 있어야 합니다. 부하 측정은 하지 않았습니다.
