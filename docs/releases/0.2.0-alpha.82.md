# Falsify Workbench 0.2.0-alpha.82

논문 입력, 웹 실행, 캔버스 비교, 사람 검수(H1) 흐름을 단순화하고 화면 간 상태 정합성을 맞췄습니다(Phase 1).

- **단일 논문 입력 공유 버스**: RED(`#paper-file`)와 BLUE(`#doc-blue-file`)에서 선택한 PDF를 웹 실행(`#hosted-ai`)이 로컬 해시만으로 즉시 공유하며, 페이지 로드나 파일 채택 시에는 업로드·게스트 세션을 호출하지 않습니다.
- **웹 실행 동선 통합 및 원클릭 지시 프리셋**: 웹 실행이 켜진 구성에서는 RED와 BLUE 모두 논문 입력 바로 아래에 웹 실행 패널을 배치하고, 수동 복붙 교환(`#external-red`, `#external-blue`)은 접힌 보조 경로로 두었습니다. 빈 지시문 상태에서는 역할별 추천 지시 프리셋 버튼으로 바로 실행을 준비할 수 있습니다.
- **웹 BLUE 지적 카드 표시 및 검수 연결**: 웹 BLUE 완료 시 수용된 지적 카드를 화면에 직접 렌더링하고 로컬 원장(`FalsifyLab.record`)에 기록하여 `검수(H1)`로 바로 이동할 수 있습니다.
- **데스크톱 1단/2단 보기 전환 및 H1 8종 판정 복원**: RED 논문 캔버스에 `1단 크게 보기` / `2단 나란히 보기` 전환과 상단 확대·축소, 인접 `실행 취소`·`다시 실행`을 배치했고, 검수(H1)에서 누락되었던 3개 판정(`원본 기존 오류`, `해석·수위 경계`, `정답표 오류`)을 포함한 8종 판정 버튼을 모두 복원했습니다.
