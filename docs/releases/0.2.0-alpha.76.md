# Falsify Workbench 0.2.0-alpha.76

운영자 Anthropic API로 웹에서 RED/BLUE를 실행합니다. 사용자는 Falsify 계정으로 로그인하고 PDF와 검토 지시를 입력합니다. 모델과 추론 강도는 고급 설정에서 선택합니다.

RED 후보를 선택하면 서버가 변경을 적용해 수정 PDF를 만듭니다. 그 파일을 내려받거나 같은 바이트를 BLUE 입력으로 전달할 수 있습니다. 표·그림 구조화 근거는 기본으로 사용하며, 기존 로컬 실행과 외부 AI 결과 가져오기도 유지합니다.

키는 서버 환경에 보관합니다. 작업·파일은 로그인한 사용자에 연결하고, 중복 접수·새로고침·취소·서버 재시작을 처리합니다. 모델 예산으로 검토가 끝나지 않으면 남은 범위를 표시하고 유효한 결과를 보존합니다.

스테이징에서 실제 Anthropic 호출, 브라우저 로그인·PDF 업로드·RED 후보 선택·수정본 다운로드·BLUE 전달과 실행을 확인했습니다. 합성 문서만 사용했습니다. 출력 파일 해시와 BLUE 입력 해시도 대조했습니다.

호스팅 편집은 텍스트와 표 셀을 지원합니다. 그래프 좌표 적용과 시각 영역 선택은 기존 편집 경로를 사용합니다. 전체 논문 재조판이나 추출 정확도 전체를 이번 API 연결 검증으로 보증하지 않습니다.

평가 준비 도구도 제공자·사용량 메타데이터를 원본 그대로 받아들이도록 맞췄습니다. 과거 실행의 비용이나 사용량을 추정해 채우지 않습니다.

PDF 모듈을 정식 pymupdf 이름으로 불러와 호환 모듈의 경고가 MCP 표준 출력에 섞이지 않도록 고쳤습니다. 실제 MCP SDK의 초기화·도구 호출 검사 7개를 통과했습니다.
