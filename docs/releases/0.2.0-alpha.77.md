# Falsify Workbench 0.2.0-alpha.77

BLUE 스캔에 논증 개요의 D3/S1 힌트를 선택할 수 있습니다. 이 힌트는 조언이며, 재현율과 거짓 양성은 측정하지 않았습니다. 원고 날짜가 있으면 인용 시점이 원고보다 늦은 참고문헌을 조언으로 알립니다. 참고문헌 대조는 Crossref, Europe PMC, OpenAlex를 봅니다. 새 호스트는 `api.openalex.org`이고, 앞의 두 색인이 일치하지 않을 때만 조회하며, 식별 정보는 보내지 않습니다. BLUE Evidence v0.4.2 묶음을 검사에 포함했습니다.

소스 사례 도구는 한 원본에서 정상본과 결함본 PDF를 같은 조판으로 만듭니다. 같은 입력이면 PDF 바이트가 같습니다. 로컬 pdfLaTeX와 matplotlib이 필요하고, 없으면 조판 검사는 건너뜁니다. 손으로 쓴 사례는 5개, 변형 집합은 46개입니다. 정답 키는 `sealed/`에만 둡니다. 인용 맞바꾸기를 포함합니다. 쌍 판정 관문은 열 가지 검사를 하고 `claims` 검사를 건너뛰지 않습니다. 모두 통과할 때만 묶음을 씁니다. `falsify corpus`는 `list`, `build`, `mutate`, `verify`입니다.

PDF 편집 대응본과 짝 코퍼스를 만들 수 있습니다. 기본 빌드는 `p*-pair-*` 16개만 고릅니다. 기록된 실행은 paired 14, sourceOnly 2, refused 0입니다. 그 14쌍은 결정적 Layer 0 센서만 측정했고, 양쪽에서 함께 탐지된 쌍은 1/14입니다. 모델 기반 탐지기는 실행하지 않았습니다. 짝 코퍼스 명령은 `falsify corpus`에 없습니다.

벤치마크 코퍼스 v5는 v4 32사례에 소스 원본 사례를 더합니다. `falsify arena benchmark`와 승격 관문의 기본은 v4이고, v5는 `--corpus-version v5`입니다. 아레나 채점은 소스 원본 원장을 받습니다. v5 센서 한 번은 298.6초, built 46, refused 0, skipped 0이었습니다. 골드 결함 46개 중 detected는 4이고, L1·L2 layer0Recall은 1/16입니다. 같은 v4 32사례의 사례별 점수는 v4와 같았습니다.

순서 바꾼 사전 판정은 범주와 항목 순서를 뒤바꾼 두 패킷을 맞춥니다. 모델 호출은 하지 않고, 불일치와 주장이 없는 항목은 사람 검토로 가며, 최종 결정은 사람이 합니다. PaperOrchestra 원본 16개 파일은 수정 없이 보관하고 출처와 해시를 고지에 적었습니다.
