# Falsify Workbench 0.2.0-alpha.96

행사 결과 판정을 결함별로 공정하게 보여 주도록 바꿨습니다.

- 규칙: 심은 결함 중 하나라도 AI가 놓치면 방문자 성공입니다. AI는 심은 결함을 모두 찾아야 이깁니다. 결함 근처를 짚은 것은 찾은 것으로 봅니다.
- 결과 화면 제목에 개수가 나옵니다. 예: 「AI가 4개를 모두 찾아냈어요」, 「4개 중 1개가 AI 눈을 피했어요」. 결함이 하나면 문구는 그대로입니다.
- 「내가 고친 곳」의 항목마다 「AI가 찾음」, 「근처를 짚음」, 「AI가 놓침」을 표시합니다. 이미 나온 결과에도 적용됩니다.
- 제출 화면과 결과 화면, 첫 화면 안내에 규칙 한 줄을 넣었습니다.
- 일부를 찾았지만 놓친 결함도 있으면, AI가 찾은 곳 설명을 함께 보여 줍니다.
- 서버(Worker)는 결과 조회에 결함별 판정(쪽, 찾음/근처/놓침)을 함께 보냅니다. 운영진이 무효 처리한 결과에는 보내지 않습니다.
