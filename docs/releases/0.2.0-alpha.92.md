# Falsify Workbench 0.2.0-alpha.92

행사 페이지(event.html)에서 고친 곳을 확인하는 화면과 편집 화면을 정리했습니다.

- 제출 화면에서 「수정본 쪽 보기」 버튼을 뺐습니다. 이제 결함 카드마다 원본과 수정본을 바로 보여줍니다.
  - 쪽 전체가 아니라 고친 곳 주변만 잘라 카드 폭에 맞춰 그립니다. 본문 글자가 편집 화면과 비슷한 크기로 보입니다.
  - 폰에서는 원본과 수정본을 위아래로 놓고, 넓은 화면에서는 나란히 놓습니다.
  - 고친 곳이 길어도 그림 밖으로 잘리지 않습니다.
- 편집 화면 탭을 「직접 고치기」와 「내 AI에게」 두 개로 줄였습니다.
  - 「Agent 코드」 탭과 레시피 코드 입력, `#recipe=` 주소 처리를 뺐습니다.
  - 아래쪽 「AI agent로 참여하기」 링크와 agent 안내 파일(agent.html, agent.md, llms.txt)도 뺐습니다.
- 폰 편집 화면에서 탭과 쪽 이동 버튼 사이의 빈 공간을 줄였습니다.
- 서버(Worker)는 바뀌지 않았습니다. 작업대 본 화면(index.html)은 버전 번호만 바뀌었습니다.
