# Falsify Workbench 0.2.0-alpha.84

AWS Community Day(2026-11-22) 부스용 휴대폰 제출 흐름을 추가했습니다. 방문자는 행사 페이지에서 공개 라이선스 논문을 골라 직접 결함을 심고, 브라우저에서 만든 수정본 PDF를 제출한 뒤 접수번호와 확인키로 결과를 확인합니다. AI 검증(BLUE)은 마감 후 운영자가 실행합니다.

- **부스 제출 API** (`/v1/booth/*`, D1 `0006_booth.sql`): `multipart/form-data`(`meta` + `pdf`) 제출, 512 KiB 청크 저장, 접수번호 `F-0001`과 8자 확인키, 확인키로 결과 조회·철회, 운영자(`fso_`) 전용 관리 경로. 저장 용량·소유자·시간당 한도는 한 번의 D1 batch 안에서 검사합니다.
- **논문 검색** (`/v1/papers/search`, `/v1/papers/pdf`): OpenAlex와 arXiv에서 CC BY·CC BY-SA·CC0 논문만 찾고 PDF를 24시간 캐시합니다.
- **행사 페이지**: 미션 카드와 쪽 이동, 문단 고르기, 「제출할 수정본 만들기」, 동의문, `#booth-result` 결과 화면, 휴대폰 44px 터치 영역. 게스트 BLUE·모델 실행과 표·그래프·그림 도구는 행사 화면에서 숨깁니다.
- **운영자 CLI** (`tools/booth/booth.mjs`): pull, close, blue, score, judge, publish, draw, missions warm.
