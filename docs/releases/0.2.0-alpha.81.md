# Falsify Workbench 0.2.0-alpha.81

이 릴리스보다 먼저 운영자가 호스팅 런타임에 paper tools와 OCR·그래프 분석 런타임을 배포했고, 운영 Worker와 행사 Worker에 `AI_PAPER_TOOLS_ENABLED`를 켰습니다. 합성 PDF에서 표 셀 수정이 새 값이 들어 있는 PDF로 나갔고, OCR 분석 작업과 그래프 분석 작업이 끝났으며, 만료된 논문은 `paper_evidence_expired_or_missing`을 반환했습니다.

올린 논문은 서버에 잠시만 있습니다. 소유자마다 최대 2개이고 유휴 7200초가 지나면 사라지며, 영구 저장하지 않습니다. 한 실제 논문에서 그림 라벨 글 편집은 리소스를 끌어올린 뒤에도 가드가 문제를 찾아, 깨진 그림 대신 「그림 안 글자를 고치면 그림이 깨져서 만들지 않았습니다. 표·그래프·그림 고치기를 쓰세요.」로 거절했습니다. 그런 그림은 「표·그래프·그림 고치기」를 씁니다.

부하 측정은 하지 않았습니다. 끄려면 `wrangler.jsonc`의 `AI_PAPER_TOOLS_ENABLED`를 `false`로 두고 배포합니다.
