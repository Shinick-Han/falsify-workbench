# Source link inventory

`readSourceLinks({bytes, document, signal})` reads a snapshot of the original PDF with the pinned MuPDF reader. `document` is the result of `readDocument` for the same bytes. The reader checks the SHA-256 and page count, validates character ranges, and returns a deeply frozen `falsify.paper-source-links.v1` inventory. The caller's bytes and document are unchanged. Abort signals are checked before reading, between pages and before return.

Each `links` entry represents one MuPDF link occurrence. Its stable ID includes the source hash, zero-based page index and occurrence index. `source.bbox` is the rectangle returned by MuPDF in its display frame. `frames` records page bounds and transforms and whether they match the document reader's frame; an unverified frame disables geometric associations. `uri` is the exact string returned by MuPDF, and `external` is MuPDF's classification. URI values are data and must be handled as untrusted strings by any renderer or output writer.

`relation.ranges` lists UTF-16 source page offsets for characters whose whole observed boxes lie inside the annotation rectangle. Overlapping boxes alone do not establish ownership. Identical character geometry is ambiguous and leaves ranges unresolved. Multiple disjoint ranges and overlapping image IDs remain separate; an asset relation identifies overlap, not proof that every pixel belongs to the link. Partial character overlaps and empty or ambiguous regions remain unresolved. The inventory preserves the link occurrence in all these cases.

Internal links include MuPDF's resolved page and destination fields where available. An XYZ point is associated with a single character or image only when the point lies in exactly one candidate. Otherwise the destination remains a page anchor. Page coordinates and destinations are source evidence, not output coordinates. A compositor must map each occurrence and target through the reflow and then inspect the generated PDF annotations; this inventory alone does not establish output preservation.
