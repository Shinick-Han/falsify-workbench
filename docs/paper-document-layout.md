# Paper document layout hints

`layoutHints(document)` accepts a `falsify.paper-document.v1` model and returns `falsify.paper-document-layout-hints.v1` with its source hash and per-page `{sourcePageIndex,status,bands,candidates,diagnostics}`. It does not mutate the model. Candidate items carry `blockId`, `kind`, `assetIds`, observed `bbox`, and `readerPosition`; original text, ranges, relations and assets remain in the input. Each figure occurrence is represented by its figure block and asset IDs, not deduplicated by image content. The caller must retain the input model. The reader-observation alternative uses reader positions where available, then original array order as a deterministic tie/fallback; missing positions are not proof of order.

For a unique gutter of at least max(12 points, 2.5% of page width), with two or more blocks each side and overlapping column extents, blocks crossing it form spanning bands. Body bands are ordered left column then right column, each top to bottom. A single-column candidate uses top-to-bottom order. Bands are purely geometric: a spanning caption is not a title, and no figure/caption relation is invented. Unlike the existing page-wide gutter heuristic, a spanning band can separate body regions. Thresholds are inherited from the existing reader's heuristic, not measured accuracy claims.

`status: candidate` means only that this bounded heuristic produced a deterministic suggestion. Overlapping spans or column items, multiple plausible gutters (including three columns), missing geometry, and page assets without a corresponding block return `status: unresolved` and only the reader-observation alternative. Other geometries may also be ambiguous even when the heuristic produces a candidate: in particular sparse side-by-side blocks, differing column layouts across bands, and semantic relationships cannot be resolved by these rules. No claim is made about original PDF coordinates; use the model's geometry provenance. Hints do not authorize a source crop, editing, dropping content, or a successful round trip. Diagnostics are local to the adapter and do not replace reader diagnostics. The adapter is not connected to the application or export.

The synthetic tests cover spanning bands, columns, one-column controls, repeated text, figure occurrence metadata, overlap, three columns, missing geometry and orphan assets. No real-paper or PDF round-trip validation has been done.
