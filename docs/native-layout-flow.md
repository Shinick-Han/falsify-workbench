# Measured continuous flow (experimental)

`composeDocument` accepts the optional `layoutMode: 'measured-continuous'`; omitting it leaves the existing path unchanged. `enginePlan` reports the requested and actual mode. Activation requires an explicitly two-column paragraph with at least 150 characters: without that evidence the existing path is used. This conservative heuristic is not a classifier for every academic document.

The material preceding that paragraph is grouped at page width. Full-page artwork and linked captions are measured together against the usable page height, with a 20 pt reserve. A group that fits uses a parent-scoped page float; an oversized group uses a breakable single-column page section. Later source single-column material uses a single-column page section instead of being silently converted to columns. This can introduce page boundaries and does not guarantee good pagination for mixed layouts. Body text, source font sizes, artwork aspect ratio, link labels, and position markers continue through the existing rendering path. No column balancing or second compilation is performed.

A float can relocate a caption relative to body text. The mode reports a flow finding until independent output image/caption ownership and permitted relocation are established. Text-check results remain separate and are not converted to a pass. Asset span markers are output position nominations, not observed image bounding boxes. `outputCheck` receives snapshots of the document and flow, the resolved font plan, and `assetSpans` in addition to its existing arguments; the raw span entries are `{id, start: {page,x,y}, end: {page,x,y}}` or null. No source rectangle is asserted as an output rectangle.

Private application-aliased PDF experiments (2026-10-28) produced a 34-page measured baseline from the 36-page sample, versus 37 pages with ordered bands. The measured candidate remains unaccepted: source caption fragments can surround unrelated figures, and the affiliation block occupies a mostly empty page. The final four text-empty pages contain visible source artwork. Raster occupancy and a shorter page count do not establish natural layout.

All eight ordered-band cases generated: baseline, previous edits, long replacements and a 600-word caption stress for each of two papers. The 36-page sample produced 37 pages with only the documented micro-sign and discretionary-hyphen representations; the single-column sample produced 15 or 16 pages with matching ordered text. Both caption stress outputs retained all 600 probe words. These checks establish content coverage for those cases, not general layout quality. Keep measured flow opt-in until the caption and title-page defects are fixed and rechecked.

The command-line proof bundles the selected source tree with the application's MuPDF aliases. Importing separate npm and vendored MuPDF instances produced different text/geometry observations and is not a valid browser-parity test. Proof manifests record the source fingerprint, runtime, prepared input, output and compiler hashes; earlier raw-import experiments are diagnostic only.
