# paper-orchestra vendor

Unmodified files from [Ar9av/PaperOrchestra](https://github.com/Ar9av/PaperOrchestra) commit `6a319132932ee031e2d759b0f7f5075cf77bd1cf` (MIT). The license text is `upstream/LICENSE`.

`receipt.json` records a sha256 for every vendored file after replacing `\r\n` with `\n`, plus one aggregate hash. The aggregate hash is the sha256 of those LF-normalized bytes in ascending path order. Each file is prefixed by its UTF-8 path and a newline and is followed by a newline. `modified` is false: nothing under `upstream/` was edited.

`tools/corpus/vendor.py` is the only loader. The companion and the hosted runtime do not import these scripts.
